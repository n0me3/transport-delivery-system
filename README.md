# transport-delivery-system
> Дипломный проект. Конфигурация 1С:Предприятие 8.3 для автоматизации
> полного цикла курьерской и межгородской доставки грузов через сеть
> пунктов выдачи заказов (ПВЗ) и сортировочных центров (СЦ).

---

## 📌 О проекте

Система автоматизирует работу логистической компании с hub-and-spoke
моделью доставки (главный хаб — Уфа). Покрывает весь жизненный цикл
посылки: от приёма в ПВЗ отправления до вручения получателю, включая
магистральную перевозку, курьерскую «последнюю милю», финансовые
расчёты и складской документооборот.

**Внешние интеграции:**
- 🖥 **АРМ-приложение на C#** — рабочее место оператора/курьера (В разработке)
- 🤖 **Telegram-бот** — отслеживание заказов по трек-номеру для клиентов

## ⚙️ Функциональность

### 📦 Управление заказами
- Оформление заказа с расчётом объёмного/расчётного веса
- Многофакторная тарификация: расстояние (по координатам × коэф. 1.22),
  вес, объём, хрупкость (+15%), температурный режим (+30%), страховка (3%)
- Генерация трек-номера (`RB + timestamp + UID`) и кода получения (6 цифр)
- Строгий конечный автомат статусов (13 состояний, матрица допустимых переходов)
- Полная история отслеживания с привязкой к оператору и геолокации

### 🚛 Магистральная логистика (Рейсы)
- Три типа рейсов: внутри зоны, к главному СЦ, от главного СЦ
- Автоматическое построение маршрута по линии городов (справочник «Зоны СЦ»)
- Интеллектуальный подбор грузов с проверкой направления движения
- Автопропуск пустых промежуточных точек
- Запрет отмены проведения (неизменность истории)

### 🛵 Последняя миля (Маршрутные листы)
- Автоподбор курьера и ТС по ПВЗ выезда
- Плановое время: 40 мин/точка
- Выполнение / отмена точек с автоматическим возвратом заказа в ПВЗ
- Учёт пробега для расчёта сдельной оплаты

### 💰 Финансы
- Полная оплата с блокировкой данных и генерацией чека
- Автоматическое продвижение заказа по статусам при оплате
- Взаиморасчёты с клиентами (регистр накопления)
- Наложенный платёж

### 📄 Документооборот
- Транспортная накладная (автозаполнение из заказа, адаптация физ/юр. лица)
- Акт приёма-передачи (4 типа, автоматическое создание при смене статусов)
- Квитанция о приёме груза
- Этикетка грузового места с **QR-кодом** (генерация через внешнее API)

### 💼 Зарплата персонала
- Оклады: пропорционально рабочим дням (Пн–Пт)
- Курьеры: сдельно за доставленные заказы
- Водители: сдельно за завершённые рейсы

### 🔧 Служебные обработки
- **Заполнение маршрутов** — автоматическая генерация матрицы маршрутов
  между всеми парами городов на основе зон СЦ и главного хаба
- **Выдача в ПВЗ** — рабочее место оператора: поиск по коду получения,
  проверка статуса, выдача с созданием акта
- **Личный кабинет клиента** — просмотр заказов, оплат, отслеживание,
  калькулятор стоимости (привязка по пользователю ИБ или телефону)

## 🔗 Внешние интеграции

### АРМ-приложение (C#)
Десктопное приложение для операторов ПВЗ и курьеров.
Обменивается с 1С через HTTP-сервисы (REST/JSON):
  Реализовано:
- Создание заказов
- Выдача заказов
  В разработке:
- Выдача заказов на доставку
- Оплата заказа
- Сканирование штрихкодов

### Telegram-бот
Позволяет клиентам отслеживать посылки без входа в 1С:
- Отслеживание по трек-номеру
- Информация о ПВЗ и сроках доставки

## 🚀 Установка и запуск

### Требования
- 1С:Предприятие 8.3.18+ (платформа)
- Файловая или клиент-серверная ИБ

### Шаги
1. Создайте новую информационную базу в 1С
2. Загрузите конфигурацию из файла `Configuration.xml`
   (или подключите репозиторий через хранилище)
3. Запустите в режиме «Предприятие»
4. Заполните справочники:
   - Населённые пункты (с координатами!)
   - Зоны СЦ и обслуживаемые города
   - Тарифные зоны и тарифы
   - ПВЗ, курьеры, водители, ТС
5. Запустите обработку **«Заполнение маршрутов доставки»**
   (укажите главный СЦ)
6. Настройте константы организации (наименование, ИНН, адрес)
